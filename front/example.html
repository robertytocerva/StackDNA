Qué es StackDNA

Cada stack tiene una secuencia. Nosotros la leemos.

Un repositorio crece capa sobre capa: frameworks, librerías, servicios, versiones. Con el tiempo nadie recuerda por qué está ahí cada pieza, ni qué tan segura es. StackDNA convierte esa complejidad en un mapa navegable.

No es un linter ni un dashboard más. Es un motor de secuenciación que recorre tu código, tus manifiestos de dependencias y tu historial de commits para construir el genoma real de tu proyecto, capa por capa.

Funciona con Node, Python, Go, Rust y Java. Se instala como CLI, corre en tu CI y expone un dashboard web para que todo el equipo lea el mismo genoma.

Cómo funciona
01

Escanear

El CLI recorre el repositorio y detecta manifiestos, lockfiles y estructura de carpetas.

02

Secuenciar

Cada dependencia se mapea a una capa del stack: frontend, backend, datos o infraestructura.

03

Analizar

Se cruza contra bases de CVEs, licencias SPDX y patrones de arquitectura conocidos.

04

Reportar

Se genera el genoma: un mapa visual y un reporte accionable, listo para PR o auditoría.
